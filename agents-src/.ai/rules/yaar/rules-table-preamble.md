---
name: rules-table-preamble
Scope: When creating any new agent file
description: Canonical sentence, present verbatim in every agent file, that introduces the Rules table and instructs reading required rules before acting.
---

Always include the following block verbatim, immediately after the `## Rules` heading and before
the table, in every agent file. Never paraphrase, shorten, or omit it.

```
The table below lists every rule that applies to this agent. Read every rule marked **required** before doing anything else. Read any other rule the moment the current action matches its Scope.
```
